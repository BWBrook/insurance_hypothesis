# Questions for the PI

These are submission facts that cannot be inferred from the repository. They do
not block the code or scientific revision stages.

1. **Funding:** Which grants or funding bodies should be named, or should the
   statement say that no specific funding supported the work?
2. **Acknowledgements:** Who, if anyone, should be acknowledged?
3. **Permanent archive:** Should the accepted data/code package be deposited in
   Zenodo, Dryad, or another named repository?
4. **AI-use statement:** Does the drafted disclosure accurately describe the
   tools and purposes used across writing, literature work, code, and analysis?
5. **Final declarations:** Please confirm the conflict-of-interest wording and
   any final cover-letter particulars immediately before submission.
