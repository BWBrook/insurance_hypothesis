# Questions for the PI

Submission facts that cannot be inferred from the repository. Answer them in one
batch at any point before step 5 of `docs/plan.md`; release decisions are listed
under step 4 there.

1. **Funding:** which grants or funding bodies should be named, with grant
   numbers, or should the statement say that no specific funding supported the work?
2. **Acknowledgements:** who, if anyone, should be acknowledged?
3. **Author details:** confirm affiliation, email and ORCID as they should
   appear on the title page and preprint.
4. **Conflict of interest:** confirm "No competing interests are declared."
5. **AI-use statement:** does the statement at the end of the main text
   accurately describe the tools and their roles in the writing, literature work,
   code and analysis?
